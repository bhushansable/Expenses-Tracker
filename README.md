# Expenses-Tracker
A simple Expense Tracker application built using Python and SQLite to help users record and manage their daily expenses and keep track of their spending.

### Features
- Add, edit, and delete expenses
- Categorize expenses (e.g., Food, Transportation, Entertainment)
- View expense history and summaries

### Installation
1 . Clone the repository
2. Install the required dependencies using pip:
   ```
   pip install -r requirements.txt
   ```
3. Run the application:
   ```
   python main.py
   ``

4. Follow the on-screen prompts to add and manage your expenses.


### Usage
- To add an expense, select the "Add Expense" option and provide the necessary details (
amount, category, date, and description).
- To view your expense history, select the "View Expenses" option.
